  - heading "导入到桌面应用" [level=4]
  - list:
    - listitem: 从插件仓库复制 npm 包名或 Git 地址。
    - listitem:
      - text: 退出 DeepSeek Harness，在已安装 dsh CLI 和 pnpm 的终端中运行：
      - code: dsh plugin --profile web add <package-or-git-spec>
    - listitem: 重新打开应用，然后在此列表确认插件已加载。
  - paragraph: 第三方插件以受信任代码运行，不受智能体沙箱保护。只安装你信任的插件。
